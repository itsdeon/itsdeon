## 🎮 Core Game Mechanics


┌────────────────────────────────────────────────────────┐
│                   ZONE 3: MAZE LEVEL                   │
│   [Pac-Man Pellet Routing, Ghost Obstacles, Safe-Zones] │
├────────────────────────────────────────────────────────┤
│             ZONE 2: STEM CHECKPOINT PORTAL             │
│   [State Pause, Interactive Arithmetic / Pattern Task]  │
├────────────────────────────────────────────────────────┤
│                  ZONE 1: HIGHWAY LEVEL                 │
│      [Frogger Timing, Dynamic Lanes, Momentum Physics]  │
└────────────────────────────────────────────────────────┘


1. **Dual Phase Gameplay**:


   * **The Transit Run (Frogger)**: Players navigate horizontal obstacle bands running at variable velocity vectors. Success requires spatial timing and velocity prediction.


   * **The Grid Maze (Pac-Man)**: Upon reaching the transit bank, players transition into an A* tile-map maze containing energy pellets, logic locks, and dynamic pursuers.


2. **Safe-Zone STEM Portals**: Reaching key checkpoints halts environmental physics and displays a dynamic STEM challenge (logic gates, arithmetic sequences, or spatial pattern matching). Solving within the window grants invulnerability and double score multipliers.


3. **Procedural Web Audio Engine**: Zero external audio assets. All sound effects—including movement chirps, collision crashes, and score chimes—are synthesized dynamically via custom oscillator envelopes (`sine`, `triangle`, `square`) in the Web Audio API.

* **Algorithmic State Machines**: The AI code generator maintained consistency across separate player modes (Frogger continuous motion vs. Pac-Man discrete tile grid alignment) without introducing frame drops or memory leaks.

## 🌐 Enterprise ADK 2.0 & MCP Orchestration


Implements Google's Agent Development Kit (ADK 2.0) patterns across distributed microservices:


1. **Model Context Protocol (MCP)**: Decoupled tool servers communicating over stdio and Server-Sent Events (SSE), standardizing tool discovery across diverse backends.


2. **Agent-to-Agent (A2A) Protocols**: Hierarchical agent coordination where a supervisor agent plans sub-goals, delegates tasks to domain-specialist agents, and synthesizes final responses.


3. **Zero-Trust Security**:


   * **SPIFFE/SPIRE Identity**: Cryptographic identity tokens provisioned per agent worker to eliminate static service-account keys.


   * **Model Armor**: Pre- and post-generation evaluation pipelines protecting against indirect prompt injection, sensitive data leakage, and unauthorized tool calls.


   * **Private Service Connect (`allapi-psc`)**: Fully isolated network boundaries routing all agentic inference and retrieval through Google private endpoints.

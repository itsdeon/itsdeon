## 🛡️ The 13-Year Convergence: AI × Security × Network

Most AI prototypes break at the network edge or get blocked by enterprise security review before reaching production. My engineering approach combines three foundational disciplines, working from frontier agent orchestration back to core packet resilience:

1. **🧠 Frontier Agentic AI & Interactive Simulation (4 Years — Cloud AI Specialist CE @ Google):**
   - Architecting enterprise multi-agent ecosystems on Vertex AI, Google Agent Development Kit (ADK 2.0), Model Context Protocol (MCP), and Agent-to-Agent (A2A) standards.
   - Rapidly prototyping zero-engine 2D/3D physics simulations, C++/Raylib/WebGL sports engines, and gamified K–12 STEM laboratories.
   - *Core Principle:* Intelligent systems must deliver real-world business agency through hardened tool integration and verifiable execution.

2. **🔒 Zero-Trust & Application Security (5 Years — Systems Engineer @ Palo Alto Networks):**
   - Designed Next-Generation Firewall architectures, Identity & Access Management (IAM), Role-Based Access Control (RBAC), encryption/decryption pipelines, Layer 7 payload inspection, sandboxing, threat hunting, and incident response.
   - Applied directly to modern AI systems via SPIFFE cryptographically attested agent identities, in-band schema validation gates (<5ms), and Model Armor runtime prompt/semantic guardrails.
   - *Core Principle:* Autonomous capability without deterministic security boundaries is an enterprise liability.

3. **🌐 Critical Network Infrastructure (4 Years — Network Engineer):**
   - Deep foundation in Layer 2 / Layer 4 routing, DNS architecture, packet-level diagnostics, and deterministic latency budgets (p95 < 1200ms, p99 < 2000ms across multi-hop agent tool chains).
   - *Core Principle:* When critical systems aren't resiliently connected, everything downstream fails.
